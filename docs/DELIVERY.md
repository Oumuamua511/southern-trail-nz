# Southern Trail NZ 正式交付说明

## 交付基线

本版本交付一份面向实际旅途使用的“2026 新西兰南岛 13 天自驾手账”。产品是可直接发布到 GitHub Pages 或任意静态文件服务器的单页网站，不需要构建、后端服务、账号系统或数据库。

正式站点：

<https://oumuamua511.github.io/southern-trail-nz/>

## 产品形态

页面按照出行前、行程中和现场查阅三个场景组织：

- 首屏集中呈现日期、航班、自驾天数、住宿和总里程。
- D01–D13 总览可快速跳转到任意一天。
- 南岛路线图展示 D04–D11 的路线与地标。
- 每日正文包含交通、活动、住宿、备选方案和注意事项。
- 行前清单包含 31 项证件、航班、租车、装备和通讯准备。
- 预算与贴士集中呈现费用、天气、补给、信号和驾驶安全信息。

桌面端采用长篇旅行杂志式布局。每日正文在 900px 及以下折叠，路线图在 820px 及以下改为横向日期选择器、地图和下置详情卡。

### 路线图交互

- D03 基督城取车和 D12 皇后镇还车是静态上下文标记。
- D04–D10 显示真实公路几何，D11 显示皇后镇本地活动环。
- 悬停路线或聚焦日期会临时预览当天，但不会覆盖已锁定的日期。
- 点击或触摸日期、路线后锁定当天；再次选择当前日期、点击地图空白处或“全程路线”可复位。
- 每天显示 2–4 个来自正文的地标；图钉支持鼠标、触摸、Enter 和 Space。
- 详情卡会同步当天标题、路线、里程或活动及所选地标，并可跳转到完整日程。

## 实际实现

### 运行架构

- `index.html` 包含语义化 HTML、全部 CSS、内联 SVG 和原生 JavaScript。
- `assets/icons/` 包含 16 枚统一风格的透明 PNG 图标及 `style-spec.json`。
- 页面使用相对资源路径，可部署在域名根路径或 GitHub Pages 项目子路径。
- 页面没有运行时 JavaScript 依赖，也没有包安装或构建步骤。
- Google Fonts 是唯一的视觉增强网络资源；加载失败时回退到系统字体。
- 住宿按钮跳转到 Airbnb 或 Booking 的外部页面。
- 行前清单使用 `localStorage` 保存在当前浏览器，键名为 `southern-trail-check-*`，不会跨设备同步。

### 地图实现

- 南岛海岸线与湖泊来自 [Natural Earth 1:10m Physical Vectors](https://www.naturalearthdata.com/downloads/10m-physical-vectors/)。
- D04–D10 公路几何由开发阶段的 OSRM / OpenStreetMap 路线简化并投影到 `900 × 760` SVG 坐标系。
- D11 是皇后镇活动点的本地示意环。
- 海岸、湖泊、路线、标注和图钉均已经内联或提交到仓库。
- 生产页面不会请求地图瓦片、地理编码或路线规划 API。
- 页面保留 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) 署名。

地图状态由 `lockedMapDay`、`previewMapDay` 和 `selectedLandmark` 驱动，统一通过 `renderMapState()` 同步按钮、SVG 路线、图钉、详情卡及 ARIA 状态。

### 渐进增强与无障碍

- 无 JavaScript 时仍可阅读全部日程、日期列表和完整路线网络。
- 日期控件使用原生按钮；SVG 路线与图钉具有键盘焦点、可访问名称和 `aria-pressed` 状态。
- 地标可通过 Enter 或 Space 激活，详情摘要通过 `aria-live="polite"` 更新。
- 页面提供“跳到主要内容”、清晰焦点样式和 44px 路线/图钉命中区域。
- `prefers-reduced-motion` 会移除路线抬升、透视和图钉延迟。
- `IntersectionObserver` 不可用时内容直接显示，不影响阅读。

## 维护边界

- 行程、住宿、预算和正文内容直接维护在 `index.html`。
- 更新地图日时，日期按钮、`.map-route[data-map-day]`、`.map-pin[data-map-day]` 和目标日程锚点必须同步。
- 地图图钉只使用正文已有的景点或活动，不加入餐厅、住宿和普通补给点。
- 可见路线与透明命中路线必须使用相同几何。
- 新图标必须遵循 `assets/icons/style-spec.json`。
- 行前清单存储键基于顺序；发布后优先在末尾新增项目。
- 线路只用于行程总览，不替代现场导航、路况、天气或封路信息。

## 兼容与可移植性

仓库不包含本机绝对路径、未提交的生成文件或运行时密钥。其他开发者只需要 Git、浏览器和任一静态文件服务器即可运行页面；执行自动校验需要 Node.js 22 或更新版本。

推荐本地启动方式：

```bash
python3 -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。不建议使用 `file://` 验收，因为浏览器对本地存储和安全策略的处理不一致。

## 发布验收

开发分支提交前和合并 `master` 后都应执行：

```bash
node scripts/verify-map.mjs
node scripts/verify-release.mjs
npx --yes html-validate@11.6.0 --rule no-inline-style:off index.html
git diff --check
```

浏览器验收覆盖：

1. 1440 × 900：日期悬停、D08 锁定、D10 临时预览、图钉选择、详情跳转和复位。
2. 390 × 844：无横向溢出、日期条滚动、D10 锁定、图钉边界、下置详情卡和每日折叠。
3. 键盘：D04–D11、代表性路线和图钉均可聚焦、激活与复位。
4. 降级：减少动态效果与无 JavaScript 条件下内容仍可读。
5. 持久化：31 项行前清单勾选后刷新仍保留。
6. 可移植：从干净克隆目录启动服务器，确认资源和交互不依赖原开发机。
7. 线上：确认 GitHub Pages 返回成功状态、页面版本与 `master` 提交一致。

GitHub Actions 会在 `master`、`codex/**` 分支推送及面向 `master` 的拉取请求中执行静态校验。

## 已知边界

- 当前地图只覆盖南岛。
- 页面不提供实时路况、天气、导航或预订状态。
- 清单数据只存在于当前浏览器，清除站点数据后会丢失。
- 离线时系统字体会替代 Google Fonts；已加载的正文和本地图标不受影响。
- Airbnb 与 Booking 链接属于第三方内容，发布前仍需人工确认可访问性。
