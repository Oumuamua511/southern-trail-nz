# Southern Trail NZ

一份面向实际旅途使用的 2026 年新西兰南岛 13 天自驾手账。正式交付形态是单页静态网站，可直接托管在 GitHub Pages 或任意静态文件服务器上。

## 当前产品形态

页面按真实旅行流程组织：

- 首屏概括日期、里程、住宿和航班等关键信息。
- 行程总览提供 D01–D13 的快速入口。
- 路线图以真实南岛海岸线为底图，按 D04–D11 展示每日路线、沿途地标和活动。
- 每日章节包含交通、活动、备选方案、住宿和注意事项。
- 行前区提供可勾选的证件、航班、租车、装备和通讯清单。
- 预算与贴士集中展示费用结构、天气、补给、信号和行车安全信息。

桌面端保留长篇旅行杂志式阅读体验；900px 及以下屏幕会折叠每日详细安排，通过顶部日期索引展开并定位当前日期。

路线图支持以下操作：

- 悬停路线或聚焦日期时临时预览，不覆盖已经锁定的日期。
- 点击或触摸日期、路线后锁定当天路线，其他路线自动淡出。
- 选中路线后显示 2–4 个地标图钉；图钉支持点击、Enter 和 Space。
- 再次选择当前日期、点击地图空白区域或“全程路线”即可复位。
- 信息卡可以跳转到对应的完整每日行程。

## 实际实现方式

- `index.html` 包含全部 HTML、CSS 和原生 JavaScript。
- `assets/icons/` 存放 16 枚透明 PNG 图标及视觉规范。
- 页面没有框架、打包器、后端、数据库、账号系统或分析脚本。
- 南岛地图是内嵌 SVG；海岸线、湖泊、路线和地标坐标已经随 HTML 提交。
- 地图运行时不会访问地图瓦片、地理编码或路线规划 API。
- 所有站内导航使用页面锚点；住宿按钮会打开第三方预订页面。
- 行前清单使用原生复选框，状态以 `southern-trail-check-*` 为键保存在当前浏览器的 `localStorage` 中，不会同步到其他设备。
- 字体从 Google Fonts 加载；网络不可用时会使用 CSS 中声明的系统字体回退。
- 页面使用相对资源路径，因此既可部署在域名根路径，也可部署在 GitHub Pages 项目子路径。

## 本地运行

项目没有安装或构建步骤。克隆仓库后，在仓库根目录启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

也可以使用 Node.js 环境中的静态服务器：

```bash
npx serve .
```

不建议把 `file://.../index.html` 作为验收方式，因为不同浏览器对本地文件的存储和安全策略并不一致。

## 内容和视觉维护

- 行程、预算和住宿信息直接维护在 `index.html` 中。
- 新增站内入口时，必须确保目标元素具有对应的唯一 `id`。
- 调整行前清单顺序会改变基于索引的本地存储键；正式发布后应尽量只在末尾新增项目。
- 新图标应遵循 `assets/icons/style-spec.json`：深海军蓝轮廓、冰川蓝辅助色和单个琥珀色路线点。
- 页面需在无 JavaScript、减少动态效果和窄屏条件下保持内容可读。

### 地图数据维护

地图使用 900×760 的固定 SVG 坐标系：

- 海岸线和湖泊轮廓来自 [Natural Earth 1:10m Physical Vectors](https://www.naturalearthdata.com/downloads/10m-physical-vectors/)。
- D04–D10 路线由开发阶段的真实公路几何简化后内嵌；页面保留 [© OpenStreetMap contributors](https://www.openstreetmap.org/copyright) 署名。
- D11 是皇后镇活动点的本地示意环，不表示一段虚构的长途公路。
- D03 与 D12 仅作为取车和还车上下文，不属于可选择的驾驶日。

更新某一天时：

1. 同步修改日期按钮、`.map-route[data-map-day]` 和对应 `.map-pin[data-map-day]`。
2. 路线的可见线与透明命中线必须使用相同的 `d` 数据。
3. 每天保留 2–4 个正文中已有的地标，不加入餐厅、住宿或普通补给点。
4. 里程采用“原计划值与真实路线计算值中的较大者”，并标记为“保守里程”。
5. 如果重新生成公路几何，只在开发阶段调用路线服务；正式页面仍应保持零地图运行时依赖。
6. 完成后运行 `node scripts/verify-map.mjs`。

## 发布与验收

生产页面由 `master` 分支仓库根目录发布到 GitHub Pages：

<https://oumuamua511.github.io/southern-trail-nz/>

每次发布至少确认：

1. 所有站内锚点均能解析，所有 `assets/icons/` 图片均能加载。
2. `node scripts/verify-map.mjs` 输出 `map contract: ok`。
3. JavaScript 语法有效，浏览器控制台没有运行错误。
4. 1440×900 桌面视口下地图预览、锁定、图钉和复位均正常。
5. 390×844 移动视口下没有横向溢出，地图日期条与每日章节可以正确定位。
6. 31 项行前清单可以勾选，并在刷新后保持状态。
7. 键盘焦点、跳到主要内容、减少动态效果和无 JavaScript 降级正常。
8. 从一个全新的克隆目录启动静态服务器，确认仓库没有依赖本机绝对路径或未提交文件。

发布流程采用开发分支提交并推送，验证通过后以非快进合并进入 `master`，再推送主分支。
